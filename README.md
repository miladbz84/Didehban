# دیده‌بان

دیده‌بان یک ربات تلگرام هوشمند برای مرجع قیمت‌های بازار است. این نسخه اولیه با Python، SQLite و python-telegram-bot ساخته شده است و برای توسعه محلی با polling آماده است. معماری پروژه به گونه‌ای طراحی شده که در آینده به webhook روی VPS یا سرویس‌های ابری قابل مهاجرت باشد.

## ویژگی‌ها

- ربات تلگرام با زبان فارسی
- ثبت خودکار کاربر و پایش فعالیت
- سیستم اسپانسر اجباری با بررسی عضویت واقعی
- قیمت‌های کریپتو، دلار، طلا و نفت
- کش در حافظه برای کاهش درخواست‌های خارجی
- پنل مدیریت برای ادمین‌ها و مالک
- سیستم خطا و لاگ فعالیت
- تنظیمات قابل ویرایش
- تست‌های pytest

## پیش‌نیازها

- Python 3.12+
- Git
- حساب تلگرام
- توکن ربات از BotFather
- کلید API Navasan و Twelve Data (در صورت نیاز)

## نصب

1. کلون پروژه:

```powershell
cd C:\path\to\didehban
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

2. فایل .env را از .env.example کپی کنید:

```powershell
Copy-Item .env.example .env
```

3. مقادیر لازم را در .env وارد کنید.

## ساخت ربات در Telegram

1. به BotFather مراجعه کنید.
2. دستور `/newbot` را اجرا کنید.
3. نام و نام‌کاربری ربات را تنظیم کنید.
4. توکن ربات را کپی کنید و در `BOT_TOKEN` فایل `.env` قرار دهید.

## متغیرهای محیطی

نمونه فایل قرار داده شده است:

```env
BOT_TOKEN=
OWNER_USERNAME=
OWNER_ID=

NAVASAN_API_KEY=
# Set these only after confirming the corresponding Navasan quote unit: IRR or TOMAN.
NAVASAN_DOLLAR_PRICE_UNIT=
NAVASAN_GOLD_PRICE_UNIT=
TWELVE_DATA_API_KEY=

OIL_WTI_SYMBOL=WTI/USD
OIL_BRENT_SYMBOL=BRENT/USD

CACHE_TTL=30

LOG_LEVEL=INFO
```

### واحد قیمت‌ها و دادهٔ قدیمی

واحد قیمت دلار و طلا در پاسخ Navasan از مستندات قابل دسترس این پروژه تأیید نشده است.
تا زمان تأیید واحد در مستندات حساب کاربری یا پاسخ رسمی ارائه‌دهنده، متغیرهای
`NAVASAN_DOLLAR_PRICE_UNIT` و `NAVASAN_GOLD_PRICE_UNIT` را خالی بگذارید؛ سرویس در
این حالت به‌جای حدس‌زدن واحد، قیمت تازه را رد می‌کند. پس از تأیید، مقدار هر متغیر
باید دقیقاً `IRR` یا `TOMAN` باشد.

حداکثر سن دادهٔ قدیمی هنگام خطای منبع، به‌صورت سیاست محافظه‌کارانهٔ داخلی چنین است:
رمزارز ۲ دقیقه، دلار ۵ دقیقه، طلا ۱۰ دقیقه و نفت ۳۰ دقیقه. این سقف‌ها تضمین
تازگی ارائه‌دهنده نیستند؛ دادهٔ خارج از سقف نمایش داده نمی‌شود.
سقف کوتاه‌تر رمزارز، نیاز تازگی بازار ۲۴/۷ را منعکس می‌کند؛ سایر سقف‌ها بودجهٔ
داخلی برای محدودکردن خطر نمایش نرخ کهنه‌اند و از دورهٔ به‌روزرسانی تضمین‌شدهٔ
منبع استنتاج نشده‌اند.

### OWNER_ID

`OWNER_ID` مهم‌ترین مقدار برای دسترسی مدیریتی است. حتی اگر `OWNER_USERNAME` وارد شده باشد، نقش مالک باید بر اساس `user_id` تلگرام بررسی شود.

برای پیدا کردن شناسه کاربر:

```text
@userinfobot
```

یا از طریق ربات‌های تلگرام که شناسه کاربر را نشان می‌دهند.

## دریافت کلید Navasan

در حال حاضر Navasan API به صورت عمومی و با کلید اختصاصی در دسترس است. به سامانه یا مستندات Navasan مراجعه کنید و کلید خود را از آنجا دریافت کنید، سپس در `NAVASAN_API_KEY` قرار دهید.

## دریافت کلید Twelve Data

1. به https://twelvedata.com/ بروید.
2. حساب بسازید و API key دریافت کنید.
3. مقدار آن را در `TWELVE_DATA_API_KEY` قرار دهید.

## دیپلوی روی VPS

برای میزبانی روی VPS یا سرور خصوصی:

1. کد را روی سرور کپی کنید.
2. Python 3.12+ نصب شود.
3. وابستگی‌ها با `pip install -r requirements.txt` نصب شوند.
4. یک فایل `.env` با مقادیر تولیدی ایجاد شود.
5. با اجرای `python bot.py` ربات شروع شود.
6. برای webhook در آینده، می‌توان `ApplicationBuilder().token(...).build()` را با تنظیمات webhook جایگزین کرد.

## پیکربندی مالک

- مقدار `OWNER_ID` را با شناسه واقعی مالک تنظیم کنید.
- اگر OWNER_ID خالی باشد، ربات در زمان اجرا هشدار می‌دهد اما به طور خودکار به هیچ کاربری دسترسی مدیریتی نمی‌دهد.
- در صورت نیاز، مالک می‌تواند از طریق پنل ادمین یا دستورات مدیریتی به عنوان OWNER ثبت شود.

## افزودن اسپانسر

- در پنل مدیریت روی «📢 مدیریت اسپانسرها» بزنید.
- گزینه «➕ افزودن اسپانسر» را انتخاب کنید.
- نام‌کاربری کانال یا شناسه آن را وارد کنید.
- ربات کانال را اعتبارسنجی می‌کند و در صورت معتبر بودن ثبت می‌کند.

## افزودن ادمین

- تنها مالک می‌تواند ادمین اضافه یا حذف کند.
- نقش‌ها: `ADMIN` و `MODERATOR`.
- اضافه کردن OWNER از طریق رابط کاربری مجاز نیست.

## ارسال پیام همگانی

- در پنل مدیریت گزینه «📨 ارسال پیام همگانی» را انتخاب کنید.
- متن پیام را نوشته و پیش‌نمایش را بررسی کنید.
- با تأیید ارسال، پیام به کاربران فعال ارسال می‌شود.
- کاربران بلاک‌شده به صورت خودکار غیرفعال می‌شوند.

## بررسی خطاها

- در پنل مدیریت، گزینه «🐞 گزارش خطاها» را انتخاب کنید.
- خطاها به صورت خلاصه و در برخی موارد با جزئیات کامل نمایش داده می‌شوند.
- تمام خطاها در جدول `errors` ثبت می‌شوند.

## مهاجرت به webhook

برای تغییر از polling به webhook:

1. وب‌هوک سرور روی VPS یا سرویس ابری آماده شود.
2. SSL و دامنه معتبر تنظیم شود.
3. در کد، `ApplicationBuilder().token(...).build()` و `application.run_polling()` را با `application.run_webhook(...)` جایگزین کنید.
4. مسیر `/` یا مسیر دلخواه را روی سرور قرار دهید.
5. متغیرهای محیطی و فایل `.env` حفظ شوند.

## تصمیمات پیاده‌سازی

در نسخه اول، دستورهای زیادی به‌صورت ساده و قابل‌گسترش پیاده‌سازی شده‌اند تا شفافیت و پایداری بالا بماند. در صورت نیاز، می‌توان بخش‌های مدیریتی و سرویس‌های بازار را به مپ‌پرها و ماژول‌های بیشتر تقسیم کرد.

## یادداشت امنیتی

- کلیدهای API و توکن ربات هرگز در Git commit نمی‌شوند.
- دسترسی مدیریتی بر اساس `user_id` تلگرام بررسی می‌شود.
- هیچ traceback یا اطلاعات فنی به کاربران عادی نشان داده نمی‌شود.
- همه پرس‌وجوهای SQL با پارامترها اجرا می‌شوند.
